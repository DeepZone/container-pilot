Detect · Decide · Update · Verify · Recover

Take control of your Docker updates.

Container Pilot detects Docker image updates, lets you approve or automate them per container, validates replacements, and restores the previous image when startup fails.

Install with Docker ComposeView on GitHub

Release candidate · Linux AMD64 and ARM64 · MIT licensed

Watchtower automates updates.Container Pilot manages updates.

Controlled, visible, recoverable

Detect

Inspect running and stopped containers and compare local image digests with Docker Hub, GHCR, GitLab, or another OCI registry.

Decide

Use manual approval or explicit per-container policies. Fixed tags never switch to latest automatically.

Verify

Wait for Docker healthchecks or a startup stability window before accepting a replacement.

Recover

Automatically restore a failed update or use the retained image-level rollback point from the Web UI.

Understand

See status, scan outcomes, last update mode, current actions, and a persistent event history.

Control access

Separate administrator actions from read-only viewer access and protect mutations with same-origin CSRF checks.

Moving from Watchtower?

Import deliberately, not blindly.

Container Pilot detects supported Watchtower selection labels, shows a policy preview, and changes only rules explicitly confirmed by an administrator.

Read the migration guide

Power requires a clear boundary

Container Pilot needs write access to the Docker socket. Run it only on a trusted management network, behind HTTPS or a VPN, and protect stateful applications with application-aware backups. Image rollback does not restore volumes or database migrations.

Read the security model
